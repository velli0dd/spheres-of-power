# Глоссарий Spheres of Power 5e

Единый словарь для перевода. Если термин меняется, он меняется здесь и затем во всех файлах
(поиск с заменой по папке `src/`).

## ⚠ Требуют решения

| Английский | Принято в черновике | Альтернативы | Почему так |
|---|---|---|---|
| augment (N sp) | **подпитка (N оч.)** | наращивание, вложение | «Усиление» уже занято сферой Enhancement |
| destructive blast | **разрушительный заряд** | разрушительный взрыв, выброс | по аналогии с официальным «мистическим зарядом» (eldritch blast) |
| blast type / blast shape | **тип заряда / форма заряда** | вид / форма | следует из предыдущего |
| Warp (сфера) | **Искривление** | Искажение, Пространство | «Искажение» легко спутать с Изменением (Alteration) |
| Universal (сфера) | **Универсальная** | Всеобщая | |
| Sphere (blast shape) | **Парящий шар** | Сфера, Шар | «Сфера» путается со сферами магии |
| Explosive Orb (blast shape) | **Взрывной шар** | Взрывная сфера | см. выше |
| draw on nature | **зов природы** | опора на природу | |
| rider effect | **дополнительный эффект** | побочный эффект | |
| Dedicated Evoker (вариант) | **Убеждённый воплотитель** | Преданный разрушитель | evocation = «воплощение» в официальном переводе |
| ghost strike | **призрачный удар** | удар призрака | |
| reanimate (способность сферы) | **оживление** | поднятие, реанимация | |
| Wraith | **Вихт** | Дух-губитель, Призрак | Ghost и Specter уже заняли «Привидение» и «Призрак» |
| Crawling Claw | **Ползающая рука** | Ползающая кисть, Ползающий коготь | |
| Physique (reanimate) | **Строение тела** | Сложение | «Телосложение» — характеристика (Constitution) |
| Trained / Training (reanimate) | **Выучка** | Обучение | в книге название непоследовательно |
