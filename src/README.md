# Исходники компендиумов сфер

Сферы и таланты больше не набираются в Foundry: их источник — Markdown-файлы в этой папке.
Компендиумы `spheres` и `magic-talents` собираются из них автоматически и при каждой сборке
**перезаписываются** — правки, сделанные в этих компендиумах внутри Foundry, пропадут.

## Как работать

1. Правите `src/spheres/<сфера>/*.md` (термины — по `glossary.md`).
2. Закрываете Foundry.
3. В папке модуля: `npm run pack`.
4. Запускаете Foundry и смотрите результат.

`npm run build` делает только JSON в `packs-src/` без сборки баз — удобно для проверки:
он сообщает об ошибках (нет `id`, дубликаты) и предупреждает о непереведённых фрагментах
и ссылках на ещё не переведённые таланты.

## Формат

```markdown
# Типы заряда                 ← папка в компендиуме для следующих талантов

## Терновый                   ← название (подпись «(тип заряда)» добавится сама по полю kind)
id: bramble                   ← латиница, уникально в пределах сферы; не меняйте после публикации
kind: blast-type              ← тип таланта из talent-kinds.json (необязательно)
en: Bramble                   ← оригинальное название
assoc: nature                 ← связанная сфера (для типов заряда)
tags: геомантия растений      ← теги из квадратных скобок книги, через запятую
prereq: ...                   ← требования (если не задано — собираются автоматически)
level: 5                      ← минимальный уровень
advanced: да                  ← продвинутый талант
repeatable: да                ← можно брать несколько раз
page: 113                     ← страница английской книги
img: icons/magic/...webp      ← иконка (необязательно; иначе — иконка сферы из spheres.json)

*Вступительный текст курсивом.*

Обычный абзац. Абзацы разделяются пустой строкой.

**Подпитка (1 оч.):** жирный текст.

### Подзаголовок

- пункт списка

<!-- заметка переводчика: в Foundry не попадает -->
```

Ссылки на другие записи превращаются в `@UUID` автоматически:

- `[[ray]]` — талант этой же сферы;
- `[[nature:create-nature]]` — талант другой сферы;
- `[[nature:]]` — сама сфера;
- `[[ray|текст ссылки]]` — со своим текстом.

Если цель ещё не переведена, ссылка остаётся простым текстом и оживёт при следующей сборке
после появления цели.

## Действия

Каждая строка `**Подпитка (N оч.):** …` сама становится действием, которое списывает N очков
заклинаний (текст подпитки уходит в подсказку чата). Отключить для элемента — поле `augments: нет`.

Броски (атаки, спасброски, урон) описываются блоком `action` где угодно внутри элемента;
в текст описания он не попадает:

````markdown
```action
name: Ваяние: конус 30 фт     ← название действия
type: save                    ← attack | save | damage | heal | utility
activation: action            ← action | bonus | reaction | special | none | minute 1 | hour 1
condition: …                  ← условие реакции (необязательно)
cost: 1                       ← списываемые очки заклинаний (по умолчанию 0)
range: 30                     ← футы | self | touch | special
target: 1 creature            ← число и вид цели (creature, object, any) или self
area: cone 30                 ← sphere 20 | radius 10 | cone 30 | cube 5 | line 120 5 | cylinder 15 15
duration: conc minute 1       ← inst | round 1 | minute 10 | hour 24 | perm; conc — концентрация
attack: ranged                ← для type: attack — ranged | melee
save: dex                     ← для type: save, можно через запятую
onsave: none                  ← none | half (по умолчанию half, если есть урон)
damage: blast | blast         ← формула | виды урона через запятую
heal: {tier}d12               ← для type: heal
variant: blast                ← добавить такое же действие с подпиткой заряда (+1 оч.)
augment: 2                    ← действие покрывает 2-ю подпитку элемента — отдельное не создаётся
```
````

Сокращения в формулах: `blast` — урон разрушительного заряда, `blast+` — он же с подпиткой,
`{tier}` — 1 кость +1 на 5, 11 и 17 уровне заклинателя, `{half}` — 1 кость + 1 за каждые 2 уровня.
Вид урона `blast` — игрок выбирает любой вид при броске. Если у заряда итоговая стоимость
от 1 оч., успешный спасбросок вдвое уменьшает урон — это сборщик ставит сам.

В формулах доступны `@spheres.casterLevel`, `@spheres.dc` (СЛ сферы), `@spheres.mod`
(модификатор ключевой характеристики), `@spheres.attack` (атака сферы).

## Новая сфера

1. Извлечь текст: `pdftotext -f <стр> -l <стр> "Spheres of Power.pdf" out.txt`
   (номер страницы PDF = номер страницы книги + 1).
2. Создать `src/spheres/<id>/` (id из `spheres.json`) и файлы по образцу `destruction/`.
   В `spheres.json` можно задать `img` — иконку сферы и её талантов по умолчанию.
3. Новые типы талантов (например, `(geomancy)`) добавить в `talent-kinds.json`.
